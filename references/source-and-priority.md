# Source roles and exam priority

## Authority by question

- Use the syllabus for schedule, grading weights, scope, and formal policies.
- Use Revision/Review decks for instructor-emphasized review topics.
- Use lecture decks for definitions, explanations, formulas, and teaching order.
- Use assignments and quizzes for practiced skills and common task forms.
- Use past exams for historical assessment patterns, never as a guarantee of future questions.
- Use answer keys for expected solution style and grading evidence when provenance is clear.

No single source type dominates every question. Surface conflicts with citations.

## Labels

- **Explicit:** directly stated as required, excluded, important, or assessed.
- **Observed:** appears repeatedly in assessed work or multiple examples.
- **Inferred:** predicted from emphasis, repetition, prerequisite centrality, or summary placement.

Attach a label and source to every ranked exam point. Never convert `Observed` or `Inferred` into `Explicit`.

## Suggested rank

- A: explicit scope or repeated assessed core skill.
- B: important supporting concept, derivation, or recurring application.
- C: context, enrichment, or low-evidence detail.

Ranking assists review; it never authorizes omission from `final-review` when the source page is substantive.
